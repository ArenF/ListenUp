## 작업 개요

### 목표
음악 맞추기 게임의 핵심 로직을 담당하는 GameService를 구현합니다. 게임 시작부터 종료까지의 전체 흐름을 관리하고, 정답 채점 및 점수 계산을 수행합니다.

### 완료된 작업
1. ✅ 게임 관련 타입 정의 추가
2. ✅ GameService 클래스 구현
3. ✅ 정답 체크 알고리즘 (Levenshtein distance 기반, 다중 정답 지원)
4. ✅ 점수 계산 시스템 (시간 보너스 + 스트릭 보너스)
5. ✅ 포괄적인 테스트 작성 (36개 테스트 모두 통과)
6. ✅ Vitest 테스트 환경 구축
7. ✅ AnswerSubmission 구조 개선 (전체 답안 정보 저장)
8. ✅ 실제 정답 카운트 추적 시스템 (correctAnswerCounts)
9. ✅ 플레이어 준비 상태 관리 시스템 (prepareNextRound, markPlayerReady)

### 주요 기능
- 게임 시작/종료 관리
- 라운드 진행 및 트랙 선택 (준비 시스템 포함)
- 정답 제출 및 채점 (다중 정답 지원)
- 점수 계산 및 순위 결정
- 실제 정답 개수 정확 추적
- 게임 히스토리 저장


**설계 근거:**
- 라운드별 모든 정보를 보존하여 게임 리플레이 가능
- `correctAnswers`를 별도로 저장하여 빠른 조회

#### 2.2 게임 시작 (startGame)

```typescript
startGame(room: Room): { success: boolean; error?: string; gameState?: GameState }
```

**구현 로직:**
```typescript
// 1. 검증
if (room.gameState.isPlaying) return { success: false, error: "이미 게임이 진행 중입니다" };
if (room.players.size < 1) return { success: false, error: "최소 1명의 플레이어가 필요합니다" };

// 2. 플레이리스트 로드
const playlist = this.getPlaylist(room.settings.playlistId);
if (!playlist) return { success: false, error: "플레이리스트를 찾을 수 없습니다" };

// 3. 게임 상태 초기화
room.gameState.isPlaying = true;
room.gameState.currentRound = 0;
room.gameState.totalRounds = playlist.roundCount;
room.gameState.answers = new Map();
room.gameState.scores = new Map();
room.gameState.streaks = new Map();

// 4. 모든 플레이어 점수 초기화
for (const [playerId] of room.players) {
  room.gameState.scores.set(playerId, 0);
  room.gameState.streaks.set(playerId, 0);
}

return { success: true, gameState: room.gameState };
```

**검증 순서의 중요성:**
1. 게임 상태 체크 (빠른 실패)
2. 플레이어 수 체크 (비즈니스 규칙)
3. 플레이리스트 존재 여부 (리소스 검증)

#### 2.3 라운드 시작 (startRound)

```typescript
startRound(room: Room, tracks: Track[]): {
  success: boolean;
  error?: string;
  track?: Track;
  roundNumber?: number
}
```

**구현 로직:**
```typescript
// 1. 검증
if (!room.gameState.isPlaying) return { success: false, error: "게임이 시작되지 않았습니다" };
if (room.gameState.currentRound >= room.gameState.totalRounds) {
  return { success: false, error: "모든 라운드가 완료되었습니다" };
}
if (!tracks || tracks.length === 0) return { success: false, error: "재생할 트랙이 없습니다" };

// 2. 라운드 진행
room.gameState.currentRound += 1;
room.gameState.answers.clear();  // 이전 라운드 답안 초기화

// 3. 랜덤 트랙 선택
const randomIndex = Math.floor(Math.random() * tracks.length);
const selectedTrack = tracks[randomIndex];

room.gameState.currentTrack = selectedTrack;
room.gameState.roundStartTime = Date.now();

return { success: true, track: selectedTrack, roundNumber: room.gameState.currentRound };
```

**개선 포인트 (향후):**
- 중복 트랙 방지 로직 추가
- 난이도별 트랙 선택 알고리즘
- 플레이어 선호도 기반 트랙 추천

#### 2.4 정답 제출 (submitAnswer)

```typescript
submitAnswer(room: Room, playerId: string, answer: string): {
  success: boolean;
  error?: string;
  result?: AnswerCheckResult
}
```

**구현 로직:**
```typescript
// 1. 검증
if (!room.gameState.isPlaying) return { success: false, error: "게임이 진행 중이 아닙니다" };
if (!room.gameState.currentTrack) return { success: false, error: "현재 재생 중인 트랙이 없습니다" };
if (!room.players.has(playerId)) return { success: false, error: "방에 존재하지 않는 플레이어입니다" };
if (room.gameState.answers.has(playerId)) return { success: false, error: "이미 답안을 제출했습니다" };

// 2. 정답 체크 (유사도 알고리즘)
const isCorrect = this.checkAnswer(answer, room.gameState.currentTrack.name);

// 3. 시간 계산
const submissionTime = Date.now();
const elapsedTime = submissionTime - room.gameState.roundStartTime;

// 4. 점수 계산
const score = isCorrect ? this.calculateScore(elapsedTime, room.settings.roundInterval) : 0;

// 5. 스트릭 업데이트
const currentStreak = room.gameState.streaks.get(playerId) || 0;
const newStreak = isCorrect ? currentStreak + 1 : 0;
room.gameState.streaks.set(playerId, newStreak);

// 6. 정답 카운트 업데이트 (✅ 2025-12-09 추가)
if (isCorrect) {
  const currentCorrectCount = room.gameState.correctAnswerCounts.get(playerId) || 0;
  room.gameState.correctAnswerCounts.set(playerId, currentCorrectCount + 1);
}

// 7. 누적 점수 업데이트
const currentScore = room.gameState.scores.get(playerId) || 0;
const streakBonus = newStreak > 1 ? (newStreak - 1) * 100 : 0;
const totalScore = currentScore + score + streakBonus;
room.gameState.scores.set(playerId, totalScore);

// 8. 답안 기록 (AnswerSubmission 객체로 저장, ✅ 2025-12-09 개선)
const answerSubmission: AnswerSubmission = {
  playerId,
  answer,
  timestamp: elapsedTime,
  isCorrect,
  score: score + streakBonus,
};
room.gameState.answers.set(playerId, answerSubmission);

return {
  success: true,
  result: {
    isCorrect,
    score: score + streakBonus,
    message: isCorrect ? `정답입니다! +${score + streakBonus}점` : `오답입니다. 정답: ${room.gameState.currentTrack.name}`,
    streak: newStreak,
  },
};
```

**설계 결정:**
- 제출 시간을 정확하게 기록하여 공정한 점수 계산
- 스트릭 보너스로 연속 정답에 대한 보상
- 즉각적인 피드백 제공 (정답 여부 + 점수 + 메시지)

#### 2.5 라운드 종료 (endRound)

```typescript
endRound(room: Room): { success: boolean; error?: string; result?: RoundResult }
```

**구현 로직:**
```typescript
// 1. 검증
if (!room.gameState.isPlaying) return { success: false, error: "게임이 진행 중이 아닙니다" };
if (!room.gameState.currentTrack) return { success: false, error: "종료할 라운드가 없습니다" };

// 2. 답안 수집
const answers: AnswerSubmission[] = [];
const correctAnswers: AnswerSubmission[] = [];

for (const [playerId, submissionTime] of room.gameState.answers.entries()) {
  const player = room.players.get(playerId);
  if (!player) continue;

  const elapsedTime = submissionTime - room.gameState.roundStartTime;
  const score = room.gameState.scores.get(playerId) || 0;

  const submission: AnswerSubmission = {
    playerId,
    answer: "",  // TODO: 실제 답안 텍스트 저장 필요
    timestamp: elapsedTime,
    isCorrect: true,  // TODO: 정답 여부 저장 필요
    score,
  };

  answers.push(submission);
  correctAnswers.push(submission);
}

// 3. 결과 생성
const result: RoundResult = {
  roundNumber: room.gameState.currentRound,
  track: room.gameState.currentTrack,
  answers,
  correctAnswers,
  scores: new Map(room.gameState.scores),
  streaks: new Map(room.gameState.streaks),
};

// 4. 현재 트랙 초기화
room.gameState.currentTrack = null;

return { success: true, result };
```

**✅ 개선 완료 (2025-12-09):**
- ✅ 답안 텍스트를 AnswerSubmission 객체로 저장하도록 구조 개선 완료
- ✅ 정답 여부를 submitAnswer에서 AnswerSubmission에 저장하도록 수정 완료
- ✅ 실제 코드에서는 answers Map이 AnswerSubmission 객체를 직접 저장함

#### 2.6 게임 종료 (endGame)

```typescript
endGame(room: Room): { success: boolean; error?: string; result?: GameResult }
```

**구현 로직:**
```typescript
// 1. 검증
if (!room.gameState.isPlaying) return { success: false, error: "진행 중인 게임이 없습니다" };

// 2. 최종 점수 집계
const finalScores = Array.from(room.players.values()).map((player) => {
  const score = room.gameState.scores.get(player.id) || 0;
  const streak = room.gameState.streaks.get(player.id) || 0;
  const correctAnswers = room.gameState.correctAnswerCounts.get(player.id) || 0;  // ✅ 실제 정답 카운트 사용

  return {
    playerId: player.id,
    nickname: player.nickname,
    score,
    correctAnswers,
    maxStreak: streak,
  };
});

// 3. 점수 순으로 정렬
finalScores.sort((a, b) => b.score - a.score);

// 4. 우승자 결정
const winner = finalScores.length > 0 ? {
  playerId: finalScores[0].playerId,
  nickname: finalScores[0].nickname,
  score: finalScores[0].score,
} : null;

// 5. 게임 결과 생성
const gameResult: GameResult = {
  roomCode: room.code,
  totalRounds: room.gameState.totalRounds,
  finalScores,
  winner,
  playedAt: Date.now(),
};

// 6. 히스토리 저장
this.gameHistory.push(gameResult);

// 7. 게임 상태 초기화
room.gameState.isPlaying = false;
room.gameState.currentRound = 0;
room.gameState.currentTrack = null;
room.gameState.roundStartTime = 0;
room.gameState.answers.clear();

return { success: true, result: gameResult };
```

**설계 포인트:**
- 게임 히스토리를 자동으로 저장
- 게임 상태를 깔끔하게 초기화하여 재사용 가능
- 우승자 정보를 별도로 저장하여 빠른 조회

#### 2.7 플레이어 준비 시스템 (✅ 2025-12-09 추가)

##### 2.7.1 다음 라운드 준비 (prepareNextRound)

```typescript
prepareNextRound(room: Room): { success: boolean; error?: string; track?: Track }
```

**구현 로직:**
```typescript
// 1. 검증
if (!room.gameState.isPlaying) return { success: false, error: "게임이 진행 중이 아닙니다" };
if (room.gameState.waitingForReady) return { success: false, error: "이미 다음 라운드가 준비되었습니다" };

// 2. 다음 트랙 선택
const currentIndex = room.gameState.tracks.indexOf(room.gameState.currentTrack!);
const nextTrack = room.gameState.tracks[currentIndex + 1];

if (!nextTrack) return { success: false, error: "다음 라운드가 없습니다" };

// 3. 준비 상태로 전환
room.gameState.nextTrack = nextTrack;
room.gameState.waitingForReady = true;
room.gameState.readyPlayers.clear();

return { success: true, track: nextTrack };
```

**설계 특징:**
- 순차적 트랙 선택 (중복 방지)
- 준비 상태 플래그 관리
- 다음 트랙 미리 로딩 가능

##### 2.7.2 플레이어 준비 표시 (markPlayerReady)

```typescript
checkAnswer(userAnswer: string, correctAnswer: string): boolean {

  const normalizedUser = normalize(userAnswer);
```

#### 1.3 Levenshtein Distance 알고리즘

**개념:**
두 문자열 간의 최소 편집 거리를 계산하는 알고리즘입니다.
- 삽입 (Insertion)
- 삭제 (Deletion)
- 치환 (Substitution)

**구현:**
```typescript
private levenshteinDistance(str1: string, str2: string): number {
  const matrix: number[][] = [];

  // 초기화
  for (let i = 0; i <= str2.length; i++) {
    matrix[i] = [i];
  }
  for (let j = 0; j <= str1.length; j++) {
    matrix[0][j] = j;
  }

  // 동적 프로그래밍
  for (let i = 1; i <= str2.length; i++) {
    for (let j = 1; j <= str1.length; j++) {
      if (str2.charAt(i - 1) === str1.charAt(j - 1)) {
        matrix[i][j] = matrix[i - 1][j - 1];  // 같으면 비용 0
      } else {
        matrix[i][j] = Math.min(
          matrix[i - 1][j - 1] + 1,  // 치환
          matrix[i][j - 1] + 1,      // 삽입
          matrix[i - 1][j] + 1       // 삭제
        );
      }
    }
  }

  return matrix[str2.length][str1.length];
}
```

**예시:**
```
"kitten" → "sitting"

    ""  s  i  t  t  i  n  g
""   0  1  2  3  4  5  6  7
k    1  1  2  3  4  5  6  7
i    2  2  1  2  3  4  5  6
t    3  3  2  1  2  3  4  5
t    4  4  3  2  1  2  3  4
e    5  5  4  3  2  2  3  4
n    6  6  5  4  3  3  2  3

편집 거리 = 3 (k→s, e→i, 끝에 g 삽입)
```

#### 1.4 유사도 계산

```typescript
private calculateSimilarity(str1: string, str2: string): number {
  const longer = str1.length > str2.length ? str1 : str2;
  const shorter = str1.length > str2.length ? str2 : str1;

  if (longer.length === 0) {
    return 1.0;  // 둘 다 빈 문자열이면 완전 일치
  }

  const editDistance = this.levenshteinDistance(longer, shorter);
  return (longer.length - editDistance) / longer.length;
}
```

**계산 공식:**
```
유사도 = (긴 문자열 길이 - 편집 거리) / 긴 문자열 길이
```

**예시:**
```typescript
calculateSimilarity("dynamite", "dyanmite")
// 편집 거리 = 2 (a와 n의 순서 바뀜)
// 유사도 = (8 - 2) / 8 = 0.75

calculateSimilarity("dynamite", "dynamit")
// 편집 거리 = 1 (e 하나 누락)
// 유사도 = (8 - 1) / 8 = 0.875 → 정답!
```

**정답 기준:**
- 유사도 > 0.8 (80% 이상) → 정답
- 유사도 ≤ 0.8 → 오답

### 2. 점수 계산 알고리즘

#### 2.1 점수 계산 공식

```typescript
calculateScore(elapsedTime: number, roundInterval: number): number {
  const baseScore = 1000;                      // 기본 점수
  const maxTime = roundInterval * 1000;        // 초를 밀리초로 변환

  // 시간 보너스: 빠를수록 높은 점수
  const timeBonus = Math.max(0, Math.floor((maxTime - elapsedTime) / maxTime * 500));

  return baseScore + timeBonus;
}
```

**점수 구성:**
```
총 점수 = 기본 점수 + 시간 보너스 + 스트릭 보너스

1. 기본 점수: 1000점 (고정)
2. 시간 보너스: 0 ~ 500점
   - 즉시 제출 (0초): +500점
   - 마지막 순간 제출 (30초): +0점
   - 선형 감소: (남은 시간 / 전체 시간) * 500
3. 스트릭 보너스: (연속 정답 수 - 1) * 100점
   - 1연속: +0점
   - 2연속: +100점
   - 3연속: +200점
```

```typescript
// socket/handlers/game.handler.ts
import { Server, Socket } from "socket.io";
import { gameService } from "../../services/game.js";
import { roomService } from "../../services/room.js";

export function handleStartGame(io: Server, socket: Socket) {
  socket.on("start-game", (data, callback) => {
    const { roomCode } = data;

    // 방 조회
    const room = roomService.getRoom(roomCode);
    if (!room) {
      callback({ success: false, error: "방을 찾을 수 없습니다" });
      return;
    }

    // 방장 권한 체크
    if (room.hostId !== socket.id) {
      callback({ success: false, error: "방장만 게임을 시작할 수 있습니다" });
      return;
    }

    // 게임 시작
    const result = gameService.startGame(room);
    if (!result.success) {
      callback({ success: false, error: result.error });
      return;
    }

    // 모든 플레이어에게 게임 시작 알림
    io.to(roomCode).emit("game-started", {
      totalRounds: room.gameState.totalRounds,
      players: Array.from(room.players.values()),
    });

    callback({ success: true });
  });
}

export function handleStartRound(io: Server, socket: Socket) {
  socket.on("start-round", async (data, callback) => {
    const { roomCode } = data;

    const room = roomService.getRoom(roomCode);
    if (!room) {
      callback({ success: false, error: "방을 찾을 수 없습니다" });
      return;

    }

    const hiddenTrack = {
      id: result.track!.id,

      endSeconds: result.track!.endSeconds,
      // name과 artist는 숨김
    };

      roundNumber: result.roundNumber,
      track: hiddenTrack,
      duration: room.settings.roundInterval,
    });

    callback({ success: true });
  });
}

export function handleSubmitAnswer(io: Server, socket: Socket) {
  socket.on("submit-answer", (data, callback) => {
    const { roomCode, answer } = data;

    const room = roomService.getRoom(roomCode);
    if (!room) {
      callback({ success: false, error: "방을 찾을 수 없습니다" });
      return;
    }

    // 정답 제출
    const result = gameService.submitAnswer(room, socket.id, answer);
    if (!result.success) {
      callback({ success: false, error: result.error });
      return;
    }

    // 제출자에게 결과 전송
    callback({
      success: true,
      result: result.result,
    });

    // 다른 플레이어들에게 제출 알림 (정답은 숨김)
    socket.to(roomCode).emit("answer-submitted", {
      playerId: socket.id,
      timestamp: Date.now(),
    });

    // 모든 플레이어가 제출했는지 체크
    if (room.gameState.answers.size === room.players.size) {
      // 자동으로 라운드 종료
      setTimeout(() => {
        const endResult = gameService.endRound(room);
        io.to(roomCode).emit("round-ended", {
          result: serializeRoundResult(endResult.result!),
        });
      }, 1000);
    }
  });
}
```

```typescript
// 힌트 요청
requestHint(room: Room, playerId: string): { success: boolean; hint?: string; error?: string } {
  if (!room.settings.allowHints) {
    return { success: false, error: "힌트가 비활성화되어 있습니다" };
  }

  const hintsUsed = room.gameState.hintsUsed.get(playerId) || 0;
  if (hintsUsed >= room.settings.maxHintsPerRound) {
    return { success: false, error: "힌트를 모두 사용했습니다" };
  }

  const track = room.gameState.currentTrack;
  if (!track) {
    return { success: false, error: "현재 재생 중인 트랙이 없습니다" };
  }

  // 힌트 생성 (예: 제목의 첫 글자)
  const hint = this.generateHint(track.name, hintsUsed);

  room.gameState.hintsUsed.set(playerId, hintsUsed + 1);

  return { success: true, hint };
}

private generateHint(trackName: string, hintLevel: number): string {
  // 레벨에 따라 다른 힌트 제공
  switch (hintLevel) {
    case 0:
      return `첫 글자: ${trackName.charAt(0)}`;
    case 1:
      return `글자 수: ${trackName.length}자`;
    case 2:
      return `일부: ${trackName.substring(0, 3)}...`;
    default:
      return "더 이상 힌트가 없습니다";
  }
}
```

### 5. 통계 및 분석

**개선 방안:**
```typescript
interface PlayerStats {
  totalGames: number;
  wins: number;
  totalScore: number;
  averageScore: number;
  correctAnswers: number;
  totalAnswers: number;
  accuracy: number;
  maxStreak: number;
  favoriteGenre: string;
}

class GameService {
  private playerStats: Map<string, PlayerStats>;

  updatePlayerStats(playerId: string, gameResult: GameResult) {
    const stats = this.playerStats.get(playerId) || this.createDefaultStats();

    stats.totalGames += 1;
    if (gameResult.winner?.playerId === playerId) {
      stats.wins += 1;
    }

    const playerResult = gameResult.finalScores.find(s => s.playerId === playerId);
    if (playerResult) {
      stats.totalScore += playerResult.score;
      stats.correctAnswers += playerResult.correctAnswers;
      stats.totalAnswers += gameResult.totalRounds;
      stats.maxStreak = Math.max(stats.maxStreak, playerResult.maxStreak);
    }

    stats.averageScore = stats.totalScore / stats.totalGames;
    stats.accuracy = stats.correctAnswers / stats.totalAnswers;

    this.playerStats.set(playerId, stats);
  }

  getPlayerStats(playerId: string): PlayerStats | undefined {
    return this.playerStats.get(playerId);
  }

  getLeaderboard(limit: number = 10): PlayerStats[] {
    return Array.from(this.playerStats.values())
      .sort((a, b) => b.averageScore - a.averageScore)
      .slice(0, limit);
  }
}
```

## 성능 고려사항

### 1. 시간 복잡도

**현재 구현:**
```typescript
startGame()          → O(n)   // n = 플레이어 수
startRound()         → O(1)   // 랜덤 선택
submitAnswer()       → O(m*k)  // m = 정답 길이, k = 답안 길이 (Levenshtein)
endRound()           → O(n)   // n = 제출한 플레이어 수
endGame()            → O(n log n)  // n = 플레이어 수 (정렬)
```

**최적화 방안:**
- Levenshtein distance 계산 캐싱
- 정답 체크 시 빠른 경로 우선 (완전 일치, 부분 일치)

### 2. 메모리 사용량

```
GameService 인스턴스당:
├─ playlists: ~1KB × 플레이리스트 개수
├─ gameHistory: ~5KB × 게임 개수
└─ 총 메모리: < 100MB (1000개 게임 기준)
```

### 3. 확장성

**현재 제한:**
- 단일 서버 메모리 기반
- 서버 재시작 시 히스토리 손실

**개선 방향:**
- Redis로 게임 상태 저장
- PostgreSQL로 히스토리 영구 저장
- 마이크로서비스 아키텍처 (게임 서비스 분리)
